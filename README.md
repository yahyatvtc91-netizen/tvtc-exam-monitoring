# نظام المراقبات – الإصدار 5.5

نظام عربي لإعداد جداول الاختبارات وتوزيع المراقبين والقاعات في الكلية. يستورد تقرير الشعب SS01 وجداول الاختبارات بصيغتي CSV وXLSX، ويتيح بناء الجدول ومراجعته. يحفظ نسخة العمل في المتصفح ويتيح تصديرها واستيرادها بصيغة JSON.

## توزيع المراقبين والقاعات

- اضبط الأيام والفترات والمدربين والتفريغ والسقوف والقيادات الإشرافية، وحدد القاعات وسعاتها.
- من «توزيع المراقبات والقاعات»، استخدم زر «توزيع المراقبين» أو زر «توزيع القاعات» لتشغيل كل عملية على حدة. يعيد النظام توزيع الخانات المفتوحة مع إبقاء التثبيتات.
- يراعي محرك HiGHS المحلي تغطية الاختبارات وعدالة الأنصبة والتفريغ وسقوف المراقبات. يتضمن المستودع [ترخيص المحرك](vendor/HiGHS-LICENSE.txt).

## التحقق من التعارضات والقيود

استخدم «فحص الجدول» أو تبويب «التحقق» لمراجعة التزامن وتعارض القاعات والمدربين ونقص المراقبين أو القاعات. يبيّن ملخص التوزيع عدد الخانات المغطاة وتحذيرات السعة والفارق في الأنصبة عند توفره.

## التقارير والطباعة

تتيح صفحة «التقارير والطباعة» طباعة جدول مدرب واحد أو جميع المدربين، وجدول المراقبة العام، وتقارير المدربين والقاعات المتاحة. يمكن حفظها بصيغة PDF من نافذة الطباعة. يتيح تبويب الإعلان طباعة جداول المتدربين لكل الأيام أو ليوم واحد. يمكن كذلك تصدير CSV لبوابة المدربين، ويتوفر [قالب Google Apps Script وتعليماته](google_apps_script/).

## تحسينات الواجهة والإشعارات

تجمع صفحة التوزيع أزرار المراقبين والقاعات والفحص وإعادة التعيين في مجموعات واضحة. يعرض النظام إشعارات موحدة لنتائج العمليات. تظهر رسالة النجاح لمدة ثماني ثوانٍ، وتبقى رسائل الخطأ والتحذير ظاهرة إلى أن تُغلق. عند تشغيل إجراء جديد، يعرض النظام إشعار ذلك الإجراء.

## التشغيل المباشر

افتح [نظام المراقبات على GitHub Pages](https://yahyatvtc91-netizen.github.io/exam-monitor/) في متصفح حديث. استخدم «تصدير نسخة العمل» من «الرئيسية» لحفظ بياناتك في ملف قابل للاستيراد.

## التنزيل والتشغيل المحلي

1. [نزّل النظام بصيغة ZIP](https://github.com/yahyatvtc91-netizen/exam-monitor/archive/refs/heads/main.zip) وفك ضغطه بالكامل.
2. افتح `index.html` في Chrome أو Edge. على Windows يمكنك فتح `تشغيل_النظام.bat`.
3. لاستكمال العمل على فصل محفوظ، اختر «استيراد نسخة» من «الرئيسية» وحدد ملف JSON.
