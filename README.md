# نظام المراقبات

تطبيق عربي لإعداد جداول الاختبارات، وتوزيع القاعات والمراقبين، ومراجعة التعارضات، وطباعة التقارير وإعلانات الاختبارات للمتدربين.

يشترك الإصداران في واجهة تفريغ الفترات، والتثبيت المستقل، وتقارير المراقبات والمدربين والقاعات المتاحة، وطباعة جدول الاختبارات وإعلانه. راجع نتائج التوزيع التجريبي في تبويب «التحقق» قبل اعتماد الجدول.

## بدء العمل

1. افتح الإصدار المطلوب. من «الرئيسية»، استورد ملف `SS01` وجداول الاختبارات بصيغة CSV أو XLSX، أو استورد نسخة عمل JSON من جهازك.
2. راجع الأيام والفترات والقاعات وتفريغ المدربين، ثم وزّع المراقبات والقاعات وافحص التعارضات في تبويب «التحقق».
3. استخدم «التقارير والطباعة» أو «إعلان جدول الاختبار للمتدربين» لطباعة الجداول وحفظها بصيغة PDF.

يمكن أيضًا تشغيل النسخة محليًا بعد تنزيل المستودع وفك الضغط، بفتح `index.html` داخل مجلد الإصدار.

## البيانات ونسخ العمل

تبدأ نسختا النشر ببيانات فارغة. تُقرأ ملفات الاستيراد داخل المتصفح وتُحفظ حالة العمل على الجهاز. لكل إصدار مستضاف مساحة تخزين مستقلة. لنقل العمل بين الإصدارين أو إلى جهاز آخر، صدّر نسخة العمل بصيغة JSON من الإصدار الحالي ثم استوردها في الوجهة.

يتضمن كل إصدار قالب بوابة المدربين في مجلد `google_apps_script`. يعمل القالب بعد إعداده في Google Apps Script وربطه بجدول المراقبات الخاص بالجهة. تطبيق GitHub Pages يعمل مباشرة من روابط التشغيل أعلاه.
